# Changelog

## 1.0.0 - 2026-08-20

- First stable ShadBlazor.FreeIcon release.
- Includes the complete 1544-icon canonical Lets Icons catalog pinned to `@iconify-json/lets-icons` 1.2.2.
- Adds strongly typed, dynamic, category, variant, search and paged query APIs.
- Provides accessible, JavaScript-free SVG rendering with per-instance SVG ID isolation.
- Supports Blazor on .NET 8, .NET 9 and .NET 10.
- Ships NuGet symbols, package documentation, code license and icon-artwork attribution.
