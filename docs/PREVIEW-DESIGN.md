# Preview Design

## Layout

Desktop application shell:

```text
Sidebar | Header
        | Main content
        | Footer
```

The sidebar becomes a compact horizontal route navigation on smaller screens.


Navigation:

- Icons
- Usage
- License & attribution
- NuGet and GitHub resources


## Icons page

Features:

- searchable, indexed and paged catalog
- featured category pills and variant filter
- responsive icon card grid
- size and color preview controls
- selected-icon metadata panel
- Razor, dynamic-name and query code samples
- local release workflow and NuGet package panels


## Theme

Uses:

- CSS variables
- Tailwind utility classes
- dark mode compatible

## Design provenance

The preview is an original Razor/Tailwind implementation using the
ShadBlazor.FreeIcon identity. External icon-browser screenshots informed only the
general information architecture; no third-party logo, screenshot, code, font or
branded copy is included. See `10-LICENSE-AND-DESIGN-PROVENANCE.zh-CN.md`.
