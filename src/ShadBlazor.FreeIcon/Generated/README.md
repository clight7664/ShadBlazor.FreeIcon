# Generated API

`FreeIcons.Generated.cs` is created by `npm run icons:sync` from the pinned
`@iconify-json/lets-icons` package. It contains one strongly typed property for every
canonical Lets Icons glyph (expected count: 1544 for source version 1.2.2).

Run `tools\commands\bootstrap.cmd` on Windows or `./tools/commands/bootstrap.sh` on macOS/Linux.
