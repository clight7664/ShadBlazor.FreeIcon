# Contributing

1. Run `eng\bootstrap.cmd` (Windows) or `./eng/bootstrap.sh`.
2. Make changes.
3. Run `eng\build.cmd` or `./eng/build.sh`.
4. If changing icon source versions, update `SOURCE-LOCK.json`, regenerate artifacts, and review attribution/license changes.
5. Do not hand-edit generated `FreeIcons.Generated.cs` or `Resources/lets-icons.json`.
